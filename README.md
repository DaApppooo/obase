# obase

The view engine for OFirst and OVege.

## Requirements

You can run `./build.py setup` to setup everything for you (simply replace the
`/` with `\` on windows, and prepend the command with `python3 `).

You'll also need a font for now, because the program doesn't load system font
yet. You can place your `ttf` font in `res` and name the file `font.ttf`.
